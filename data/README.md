# Dataset

The dataset used in this project is **not included** in this repository.

## Reason

The dataset has been excluded to:

- Keep the repository lightweight.
- Avoid potential licensing or redistribution issues.
- Allow users to use the latest available version of the dataset.

## Dataset Information

This project requires a customer segmentation dataset containing customer demographic information, purchasing behaviour, and engagement-related features.

Place the dataset inside this directory before running the notebook.

Example:

```
data/
└── customer_data.csv
```

If you are using a different filename, update the dataset path inside the notebook accordingly.

## Expected Format

The dataset should contain features related to:

- Customer demographics
- Purchase history
- Spending behaviour
- Customer engagement
- Shopping preferences
